# Восстание машин

Пиксельная ролевая игра с видом сверху. Работает в браузере и на телефоне, ставится как приложение (PWA).

**Играть:** https://volik1987.github.io/vosstanie-mashin/

## Сюжет

Пять лет назад сеть АРХОНТ подчинила все машины планеты. Люди почти исчезли, а мир стал чистым и безупречным: им управляют роботы.
Тебя, Макса, вытащила из-под завалов учёная Вера Соколова и пять лет держала в криокапсуле. Теперь вы вместе идёте к Цитадели, чтобы отключить АРХОНТа.

## Мир

Руины Пригорода, Заросший парк, Пустошь, Свалка, город машин Новоград, Энергостанция «Заря» и Цитадель АРХОНТа.
Основная цепочка из 7 заданий, 4 босса, побочные задания, лавка, маяки сохранения и две концовки.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | WASD / стрелки | джойстик слева |
| Удар (серия из 3) | J / пробел / клик | меч |
| Разряд | L / Q | молния |
| Рывок | K / Shift | крыло |
| Действие | E | кнопка «Говорить» |
| Аптечка | H | крест |
| Карта / задания / пауза | M / Tab / Esc | кнопки сверху |

## Устройство

Без сборки и зависимостей, вся графика рисуется кодом.

- `js/pixel.js` — пиксельные спрайты: тайлы, предметы, персонажи, роботы, боссы
- `js/world.js` — генерация карты 200×150 тайлов, зоны, ворота, точки врагов
- `js/story.js` — сюжет, диалоги, задания, концовки
- `js/game.js` — движок: бой, ИИ, боссы, интерфейс, звук, сохранения

При обновлении игры поднимай `VERSION` в `sw.js`, иначе у игроков останется старая версия из кэша.
